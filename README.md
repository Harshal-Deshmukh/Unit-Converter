# 🔄 UnitConverter

A simple Android app to convert between different units.

## ✨ Features
- Convert multiple units
- Simple and clean UI
- Instant results

## 🛠️ Tech Stack
- Kotlin + Jetpack Compose
- MVVM Architecture

## 🚀 Getting Started
1. Clone the repo https://github.com/Harshal-Deshmukh/UnitConverter.git
2. Open in Android Studio
3. Run the app
